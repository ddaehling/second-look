# Second Look

A researched compendium of saved AI and technology posts, with practical examples, source links, impact scores and original-post embeds.

**Read it:** https://ddaehling.github.io/second-look/

This edition contains 258 reports and 85 brief mentions. Research last updated: 2026-11-09.

This repository contains only the published static reader and the assets it uses. Raw bookmark captures, research working files and maintenance snapshots remain outside it. Images retain their individual source credits; the Archivo font licence is in assets/Archivo-OFL.txt.

Reading progress stays in each browser and origin. To transfer progress from the local reader, use its Export reading state button, then Import reading state here. Nothing is uploaded with that import.

GitHub Pages serves the main branch from its root. The .nojekyll file keeps the build static. Updates are prepared from the validated local edition; no signed-in X access runs on GitHub.
